# F1 Strategy Analytics System

A professional race strategy simulation engine inspired by real Formula 1 performance engineering.

## Project Overview

This system models Formula 1 race strategy using:

- Tire degradation modeling
- Pit stop optimization
- Monte Carlo simulation
- Traffic probability modeling
- Risk-adjusted scoring
- Real telemetry ingestion via FastF1
- Machine learning regression for lap time prediction
- Interactive Streamlit dashboard

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-Learn
- FastF1 API
- Streamlit
- ReportLab

## Features

### Strategy Engine
- Multi-compound simulation
- Optimal pit stop search
- Deterministic and probabilistic modeling

### Monte Carlo Engine
- 1000-run simulation
- Traffic randomness
- Risk-adjusted scoring

### Real Data Integration
- Monaco 2023 race data
- Hamilton lap extraction
- Tire degradation curve fitting

### Machine Learning
- Linear Regression
- Polynomial Regression
- Random Forest
- Train/test validation
